# Triage Labels

| 角色 | GitHub 标签 | 用途 |
| --- | --- | --- |
| 待分诊 | `needs-triage` | 范围或优先级尚待判断 |
| 待补充 | `needs-info` | 缺少复现信息或用户决策 |
| 可由 Agent 执行 | `ready-for-agent` | 交付与验收明确，仍需检查 blocker |
| 需人工处理 | `ready-for-human` | 必须由用户或人工执行 |
| 不处理 | `wontfix` | 已决定不实施 |

保留 GitHub 既有 `bug`、`enhancement`、`documentation` 标签描述任务类型。发布任务时只创建实际需要且尚不存在的标签，不批量修改已有 issue 的标签。
