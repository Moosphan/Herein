## 3. 对首版问题的具体纠偏

### 汉武帝：成熟君主，而非持简微笑的泛化文官

这是一种艺术定位，不是已核实的真实面貌。重绘选择成熟而克制的统治者：头颈中轴稳定，下颌有体积，视线有明确落点；眉弓、眼眶、鼻梁和口部服从同一头部转向。嘴闭合，嘴角不提，眼睛不过度睁大；不通过歪鼻、斜眼或压成一条线的眉毛表达威严。

衣袍以肩、肘、腰等受力点组织宽折，少量暗面说明袖筒和交领关系；不用遍布全身的短笔制造“花衣”或粗糙皮肤。冠、领、袖、带应各有连续结构，不能用随机金边堆出身份。

### 霍去病：青年军事人物，而非坐直微笑的展示骑手

年轻、精瘦、敏锐是本次角色设计选择；具体容貌仍属创作。用面部较短的成熟纹理、清楚的颌颈承接、集中向前的视线区分青年与中年。躯干、骨盆、上臂与手的方向共同说明他在观察或行动；若持兵器，手掌必须围绕杆身，手臂长度与肩肘位置一致。

甲胄先是能包住胸腹和肩臂的体积，再附甲片；不要先铺整齐方格，再假定它已经是盔甲。披风从固定处出发，受力与风向统一。新构图可用半身、站姿或更清楚的骑姿，角色定位优先于复用首版姿态。

### 赤兔：胸廓、骨盆与关节明确的马，而非拉长躯干的四肢拼装

先确定头颈、胸廓、腰腹、骨盆、肩胛与四肢的连接，再选一个可读的运动瞬间。远近腿在空间上错开，关节转向不靠随意折线；蹄部接续掌骨，鬃尾随动势。头部应有额、鼻梁、颊与口鼻的不同面，不把眼、鼻孔当贴在平面上的符号。

赤兔属于单独的文学骏马意象，不与两位西汉人物拼成同一史实事件。新作可以取消马具来集中考察形体与动势。

## 4. 实施与审图规则

1. 先定每作的一句角色定位、头部朝向、视线和主要动作，再画剪影。不要在旧版错位五官上继续加纹理。
2. 灰阶检查头、颈、胸廓、骨盆和肢体的大面；缩略图先能识别身份与动作。头部用共享的中线、眉线、鼻底与口部基准定位，避免各特征孤立摆放。
3. 褶皱从肩、肘、腰带等锚点出发，明暗随衣料转折；皮肤、织物和金属不能使用同一套噪声。
4. 实际打开脸部、手部和马腿裁切看图；同时看全幅，修局部时不破坏整体比例。
5. 在暖纸、白底、深底检查透明边缘；身体体积不能靠背景填色补洞，滤镜不能掩盖骨架错误。
6. 交付时如实称为原创艺术意象，不将角色设计 Skill 当作历史服饰依据。本次没有取得可支撑特定冠服、马具细节或真实肖像的博物馆一手资料，因此不作该类复原声明。

完整复用边界仍遵守 [中国古风元素绘画 Skill](../../resources/skills/chinese-ink-elements/SKILL.md) 的透明导出与视觉验收规则。
