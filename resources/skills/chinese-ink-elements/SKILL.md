# 中国古风元素绘画

把自然、古建、人物与器物画成可独立复用的中国古风意象。基础定调是有结构的墨块、干湿笔触、透气留白和清楚的主次；颜色按物体材质、季节、地域、时代语境和叙事气氛自由发挥。青灰淡赭是早期九景的一种方案，不是整个技能的固定色板，也不要求每件物体染成墨绿。用户给出的参考、配色与用途优先。

## 先确定画什么、放哪里

从当前对话提取题材、用途、底色、尺寸、文字预留区和输出格式。已提供的信息直接沿用；缺少非关键参数时采用下面的起点，并在交付时说明。只有缺失信息会改变结果时才提问。

| 项目     | 默认起点                                           |
| -------- | -------------------------------------------------- |
| 任务     | 新画可复用元素或组合场景，代码绘制                 |
| 坐标     | 1600×1000，透明背景                                |
| 展示底色 | 暖牛皮纸 `#dfc69c`，只存在于预览层                 |
| 表现     | 写意水墨或彩墨；先形体结构，再笔触与设色           |
| 系列关系 | 统一笔墨与层次；同一系列协调色彩，各物体保留材质色 |
| 文字     | 题字和印章默认放展示层，主体素材保留无字版         |
| 输出     | 可编辑 SVG；有兼容渲染器时同时导出透明 PNG         |

具体朝代、古迹、器物复原或真实地图有事实要求时，先取得依据；没有依据的画面标作原创意象。绘画素材不自行改动宿主应用的主题、控件或业务流程。

## 创作顺序

1. 写出一句构图意图，例如“右侧主峰、左下疏松，中部留江，左上留标题”。为主体、陪体、留白分别确定位置。
2. 先用三至五档墨度建立形体、遮挡与前后关系。缩成缩略图，检查主体能否辨认。
3. 根据物体材料与叙事场景选择主色、辅色和重点色，再用冷暖、明度和局部墨色统一。允许朱红宫墙、金黄瓦面、青蓝远山、铜褐器物和多色花木；背景协调不等于统一染绿。建筑墙体承担遮挡，门洞、桥洞承担透景。
4. 用短皴、侧锋、点苔和少量清晰枯笔说明材质。笔触跟随山势、枝干或屋面方向。
5. 加入有主次的花、舟、鸟等点景，整理文字预留区。系列新作至少改变主体关系或空间组织；仅换随机种子不算重新设计。
6. 渲染并查看实际文件，按质检规则修正最明显的问题，再导出与说明。

默认以程序化 SVG 完成；需要更真实的湿墨扩散时可选择 Canvas/WebGL。用户选择生图模型时沿用本技能的视觉规则，使用当前可用的图像工具，并如实说明栅格结果的透明度和可编辑性。

## 三条关键结构约束

- **山石有面**：峰脊转折决定体积；短皴附着坡面，远山减少纹理，根部消入留白。
- **古建相接**：塔身、屋檐、墙、柱与台基有连续承接；屋檐薄而有暗面，墙体遮住后景。
- **笔墨有别**：湿染负责宽色块和软边，干笔负责转折与质地；各部分的清晰度有主次。

色板、结构、留白与实际目标底色共同决定观感。整幅模糊、规则长划痕、重复黑檐板会破坏这三条约束，具体修正见质检资料。

## 包内资源怎么用

`assets/approved-collection.png` 是早期青灰淡赭九景的样本，用于理解结构、笔墨与构图密度；其中色板不限制新作，纸底与小标题属于展示。

`scripts/generate-studies.mjs` 封装九景原创生成代码，可独立运行，无第三方依赖：

```bash
node "<技能目录>/scripts/generate-studies.mjs" --out "<输出目录>" --scenes pagoda-pines,lotus-pond
```

运行 `--list` 查看九个样本，`--help` 查看参数。输出 SVG、`catalog.json` 与预览页。脚本保留样本原色，不是任意物体自动配色器；新作在输出工作区中改编色板、材料渐变与构图。默认不覆盖已有生成文件；修改后重跑同一目录时显式传 `--overwrite`，保留安装目录中的样本。

需要透明 PNG 时，按代码资料使用 `scripts/render-assets.cjs`，或者采用现有可信的 Chromium 渲染器。没有可用渲染器时交付 SVG 并明确 PNG 尚未导出。

`scripts/generate-expanded-studies.mjs` 是文房、玉漆、礼乐、军械、货币、织造、水利与花鸟等十二款新增样本，零第三方依赖。使用 `--list` 选题，显式指定输出目录；同目录重画时传 `--overwrite`：

```bash
node "<技能目录>/scripts/generate-expanded-studies.mjs" --out "<输出目录>" --scenes jade-disc-tassel,apricot-two-swallows
```

脚本生成透明 SVG 与清单，PNG 另行渲染。它提供可改编的画法实例，装饰器物与机制意象不作为特定文物或工程复原。

## 完成交付

提供可见预览和源文件位置，说明尺寸、透明性、可拆组部分、实际检查结果及必要限制。保证预览与源文件是同一版本；优先交付新作品本身，简述相对旧版改变了什么。

这是一套水墨风格的程序化表达方法。滤镜不是宣纸物理仿真，通用古建也不自动代表某座真实古迹。
