# 视觉验收与纠偏

## 先看图，再看参数

实际打开刚生成的 SVG/PNG。文字描述、成功退出码和存在的文件都不能代替看图。优先使用现有图像查看工具；若环境不能查看，就明确说明视觉检查未完成。

顺序：缩略图看构图与主次 → 中等尺寸看结构 → 原尺寸看笔墨与导出边缘。先改最明显的一类问题，再重渲染检查；无需为低影响静态素材增加整套应用测试。

## 六项视觉判断

| 项目 | 通过表现                                 | 需要调整的表现                               |
| ---- | ---------------------------------------- | -------------------------------------------- |
| 结构 | 山有转面，塔有承接，枝有粗细，舟有接水   | 模糊团块、漂浮屋檐、直斜木棍、断开的茎       |
| 构图 | 主宾明确，负形连通，近远可读             | 一排孤立图标、同高山峰、到处同样清晰         |
| 笔墨 | 墨块为主、干湿有别、皴随形走             | 均匀轮廓线、整幅糊、重复长划痕               |
| 设色 | 材质与场景用色明确，主次、冷暖和底色协调 | 所有物体染成同一灰绿，颜色失去主次，底色补丁 |
| 复用 | 透明边缘自然，实际尺寸可读，分组合理     | 白洞、纸纹烘焙、缩小只剩噪点、滤镜裁边       |
| 系列 | 保留共同笔墨与层次，各场景可有不同配色   | 同图镜像、换种子或改题名冒充新构图           |

这些是审美判断，不用编造“得分达标”或把任意面积比例当成客观证明。用户已明确认可的部分优先保留，修改针对反馈。

丰富配色、较大面积朱红或金黄本身不构成问题；判断其是否符合物体、叙事和整幅主次。九景参考图的墨绿倾向不作为新作的验收要求。

人物还需按 [人物绘画](figure-painting.md) 检查骨相、视线、头颈与领口承接、手和工具接触，确认相邻人物没有复用同一张脸。动物按 [活体绘画](living-animals.md) 检查头胸骨盆、关节、重心及近远肢；白羽和浅毛保留实体材料色。脸、手、马蹄等关键处单独出放大图，不能只凭整幅缩略图判断。

器物按 [材料指南](objects-and-materials.md) 检查口壁、透孔、材料色与表面附着；构造场景按 [构造指南](craft-and-constructed-scenes.md) 检查吊点、支架、弦、轴、经线和水路。局部放大应能看清“谁承接谁”，比如壶底与炉口、绳与钱孔、钟与悬绳；技术结构不明确时保留装饰意象标注，另查来源再作机制图解。

## 观察到的问题与可操作的修正

| 现象              | 常见原因                             | 首选修正                                  |
| ----------------- | ------------------------------------ | ----------------------------------------- |
| 山像灰泥或圆包    | 模糊过大、剪影无转折、纹理替代了结构 | 重画峰脊与暗面，降低湿染模糊，再附短皴    |
| 山上有长平行划痕  | 相同长度、走向和宽度贯穿整座山       | 皴纹拆成短段，跟随不同坡面，局部加入点苔  |
| 塔像悬空叠盘      | 先画檐而忽略连续墙身                 | 重算各层 wallTop/wallBottom，先画墙再盖檐 |
| 檐口过厚          | 多条浓黑笔叠在同一边                 | 收窄暗带，以屋面体积而非黑线形成重量      |
| 后山穿过墙        | 墙体组透明度过低或材料色 alpha 过弱  | 用实体材料色遮挡，再在墙内加局部淡染      |
| 桥下出现方块      | evenodd 的内洞伸出外形形成奇偶填充   | 画单个拱圈闭合路径，或修正洞口范围        |
| 荷叶像塑料圆片    | 规则外轮廓、均匀透明、只有径向线     | 改卷边缺口与前后遮挡，增加局部墨面        |
| 梅干像木棍        | 粗直轮廓、下端平切、枝干接合突兀     | 弯折干势、根部外撑、侧枝逐级收细          |
| 竹像重复贴纸      | 相同叶片、相同簇向和等长节           | 按枝势重组叶簇，改变节长和主陪墨度        |
| 柳像竹或稀疏短刷  | 阔叶、短枝、等距等长垂线             | 细长披针叶贴合长软枝，分层浓密、同向风姿  |
| 草穗像断头或折杆  | 穗头单独旋转，草茎仍接原坐标或有多余短杆 | 共用变换后的穗基和切线，穗轴短距接入草茎 |
| 亭子歪斜或不承重  | 梁栏台基各自用不同斜率、撑件悬空     | 建立共同投影，逐一核对屋面到台基的接触链  |
| 玉孔壁透出纸色    | 将整个孔区镂空或孔壁透明过强         | 先画实体内壁的玉色暗面，只留真实可见通孔  |
| 换底后露白边      | 纸底或白洞已画进素材                 | 改为 alpha/真实镂空，材料白另保留         |
| SVG 与 PNG 差异大 | 渲染器不支持滤镜、旧 PNG 未更新      | 用目标 Chromium 重导出并比较同一版本      |
| 新款看起来仍一样  | 只改种子或颜色                       | 先改主体关系和负形，再改局部题材          |

## 技术验收

- SVG 可以解析，尺寸和 viewBox 有效，坐标中没有 `NaN` / `Infinity`。
- ID 唯一，滤镜、渐变、mask、clip 和 ARIA 引用都能解析。
- 自包含版本无脚本、事件属性、远程图片或字体；渲染不依赖原工作区的绝对路径。
- PNG 的实际尺寸符合声明；检查 alpha，画面有墨迹，要求透明的背景和洞口确实透明。
- 原尺寸不截笔缘；200–500px 的目标使用尺寸仍可识别。
- 在目标暖纸、白色、深色或棋盘底查看边缘。浅色实体材料与背景补丁要区分。
- 预览页在实际窗口宽度可浏览下载；没有可用 PNG 时不能显示“已导出”。

不要用“所有角落必须透明”作为每幅画的通则：满幅枝叶可能碰到角落。判断应根据作品约定的透明区；脚本只做基础 alpha 检查，洞口与布局需要看图或针对该场景取样。

## 一次小批量评审

1. 选一个能代表本批关键结构的作品先做，例如山塔同时存在的场景。
2. 先确认色调、结构、透明洞口和实际尺寸，再扩为系列。
3. 出一张编号或题名联系图，逐张看有没有机械复用。
4. 用户要求修改一款时保留其他已确认作品，避免全组风格漂移。

若仍有可见问题，明确指出待调整项，不用“完全还原水墨”或“历史级复原”等无法由当前代码证明的表述。
