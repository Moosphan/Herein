## 风格范围

基准是有笔墨感的中国古风绘画，可采用水墨、淡彩、彩墨或局部较浓设色：先有能辨认的形体与空间，再用色彩、笔触和细节表达材质与叙事。它适合古代历史视频的页面点景、章节过渡与解释性画面，不把程序化表达声称为某个画派的正统技法。

新作延续结构、清晰度层次、笔触关系和留白方式；色温、饱和度与具体颜色服从题材。用户已明确允许丰富色彩，不需要先征求“能否不用墨绿”；颜色选择属于创作判断。用户指定工笔、重彩、纯墨或新纸色时相应调整。

## 按物与境设色

1. 识别材料：木、石、瓦、铜、铁、玉、瓷、丝、皮革与植物各有不同的色泽和反光关系。
2. 识别场景：春花、秋林、雪夜、宫廷、边塞、集市与战争允许不同色温、对比和色彩密度。
3. 选择一组能突出主题的主色与辅色，重点色的数量和面积由画面需要决定。可同色系，也可冷暖对照，不规定只能三色。
4. 用共同的明度节奏、墨色、颗粒和边缘软硬把色彩收进画面。暖纸需要协调，但允许蓝、红、黄、紫等有明确存在感。
5. 涉及真实文物、朝服或建筑彩画时，颜色也是史实的一部分，按依据处理；装饰意象可自由发挥并标注性质。

## 色板和墨度

### 早期九景的暖纸组合

这是已经产出的青灰淡赭样本配方，保留用于复现。新题材可以替换整套主辅色，不需要每次沿用灰绿屋面、青灰山体或小面积朱砂。

| 角色     | 起始颜色                          | 使用方式                               |
| -------- | --------------------------------- | -------------------------------------- |
| 展示纸底 | `#dfc69c`                         | 牛皮纸预览底，不写进透明主体           |
| 主墨     | `#343c36`                         | 枝干、近景暗面、门窗、重点笔触         |
| 矿物灰绿 | `#526c61`                         | 山面、荷叶与屋面辅色                   |
| 淡赭     | `#927252`                         | 向光坡面、土岸、木石暖色               |
| 远山青灰 | `#697a7c` / `#798786`             | 低对比远景，随深度减淡                 |
| 屋面     | `#748074` → `#4b5c50` → `#303d34` | 屋脊向檐下的轻重变化                   |
| 暖墙     | `#c3b08b` / `#dfc9a3` / `#a29373` | 连贯实体墙身与侧面；透明背景上仍要遮景 |
| 朱砂     | `#8c4836`                         | 小印、花心或很少量的语义重点           |
| 花卉     | `#e1c4b1` / `#c69783` / `#e9d8b5` | 藕粉、淡胭脂和米白，小面积使用         |

这套样本以偏冷远景与偏暖近景建立层次。其他作品也可以采用暖远景、冷近景或更强烈的红金组合；先在目标底色上看明度、冷暖和主体识别，再决定配色面积。

### 五档墨度的实用起点

下表是 1600×1000 SVG 在暖纸上的调参起点，指形体组或笔触的 `opacity`，不是最终像素透明度。

| 墨感 | 常用起点  | 用途                           |
| ---- | --------- | ------------------------------ |
| 清   | 0.08–0.18 | 薄雾、极远山、水面轻痕         |
| 淡   | 0.18–0.32 | 远峰、陪山、后层树影           |
| 重   | 0.35–0.55 | 中景山面、浅皴、土岸           |
| 浓   | 0.60–0.80 | 主体树冠、建筑暗面、近岩       |
| 焦   | 0.80–0.95 | 极少量枝干转折、门洞与落笔重点 |

实际透明度还会乘上填色、渐变、滤镜和父组的 alpha。例如父组 0.65 乘渐变 0.58，局部在颗粒处理前就只有约 0.38；不能只看父组参数就判断浓淡。墙体、花瓣和船帆属于材料色，可用较实的填色，避免后景从实体中透出。

## 构图和系列变化

### 先安排三种关系

1. 主体与陪体：一个最有识别力的形体，其他元素支持它。
2. 实与虚：近景落墨、远景减弱；空处成为江面、雾或文字空间。
3. 藏与露：后景有遮挡，近景有着落；不把所有物体完整排成一行。

### 可选的空间骨架

| 骨架     | 适用题材         | 调整重点                                     |
| -------- | ---------------- | -------------------------------------------- |
| 右实左虚 | 山峰、梅树、古塔 | 主体在右，左上或左侧可放正文；小陪体平衡重心 |
| 两岸夹江 | 峡谷、帆船、行旅 | 主体两侧错落，中部负形连通至远景             |
| 横桥接岸 | 江南、水乡       | 桥决定横向节奏，桥洞是亮面，舟成为小焦点     |
| 门中借景 | 园林、书院       | 近墙实，门洞透出更淡的山与庭院               |
| 重檐中轴 | 宫阙、礼制意象   | 主体轴线稳定，以远山、疏松与配殿打破板正感   |
| 近花远水 | 荷塘、节气       | 叶片成组叠压，花和小虫控制点睛密度           |
| 横斜枝势 | 梅、松、竹       | 枝干的主势先成立，局部转折不平均分布         |

侧边装饰可把主体集中在一侧约一半画幅，标题预留区从画幅的约四分之一开始试排；主视觉则可增大形体。留白面积由实际文案与用途决定，不能为了固定百分比裁掉结构。

### 多款作品如何避免重复

至少改变一项空间关系，并同时改变一项主体设计。例如“山后古塔”改为“近岸桥洞与归舟”，或“直立古梅”改为“横枝跨水”。可以沿用色板和笔触原语。

只改种子、镜像、题名、滤镜强度或印章位置，是变体；交付时应如实称为变体。九景生成器提供的是已知构图样本，新任务不必被这九种限制。

## 干湿、皴染与边缘

### 落笔次序

1. 用大面积墨色或适合材质的底色确定山体、墙体、叶片等体积。
2. 根据朝向、光源与材质增加局部冷暖和暗面，不固定向光面必须淡赭。
3. 用少量短皴、枯笔或点染说明材质。
4. 保留少数最清晰的边缘，把次要边缘化入雾、水或纸底。

山面皴纹顺着坡面的受力与转折走；树皮随枝干弯曲；屋瓦随屋面投影向檐口展开。随机数用于局部压力、间距和墨粒变化，不能替代形体结构。

### 1600×1000 坐标中的滤镜起点

| 处理 | 已验证起点              | 边界                               |
| ---- | ----------------------- | ---------------------------------- |
| 笔缘 | 位移约 3.8，模糊约 0.32 | 小幅破边，细节仍可辨认             |
| 湿染 | 位移约 11，模糊约 1.1   | 仅作用于宽色块，不模糊整幅画       |
| 墨粒 | 低透明噪声经 alpha 合成 | 在已有形状内改变浓度，避免外部铺灰 |
| 枯笔 | 较高频噪声与源形状相交  | 留住笔势主体，避免细线全部被掏空   |

改变 `viewBox`、目标尺寸或缩放层级后重新检查上述值。滤镜区域适当扩张，防止边缘被裁；噪声尺度也要随画面尺度调整。滤镜只近似干湿颗粒，不能证明真实毛笔或宣纸扩散。

## 透明素材与背景

素材层：墨色、材料色、局部阴影与必要遮挡。展示层：纸色、纸纹、题字、印章和下载界面。主体需要题字时另外输出带字版本。

雾、江面、桥洞和月门洞优先通过 alpha、遮罩或真实镂空产生。白色涂块放到牛皮纸上会露出白洞；纸色涂块换底后会露出补丁。建筑墙面、荷瓣与帆布则是材料本身，可以有浅色实体。

在目标纸色、白色和深色/棋盘底各看一次。深底检查用于找背景补丁与边缘光晕，不要求同一淡墨素材在所有底色上具有相同视觉强度；用户需要深底成品时另调墨度或输出专用版本。
