# 百工与春华 · 彩墨十二景

新增十二幅独立构图，延续暖牛皮纸上的彩墨定调。木石、谷物、纸绢、朱赭、紫葡、白花与钴青羽毛各有材料色；纸底只在预览中出现。保留此前所有已认可作品，包括修订的驿站、渡口、双鲤、铜镜与印信。

| 作品 | 构图与画法重点 |
| --- | --- |
| 麦香石磨 | 上下磨盘体积、入粮孔、磨齿、木柄与出粮槽，侧置麦束粮袋 |
| 雕版留香 | 斜置木版、黑墨刻纹、墨刷、揭起的纸张与装订书册 |
| 珠算筹思 | 上二下五珠、纵杆与横梁，散置算筹与纸卷 |
| 市衡量谷 | 提绳支点、吊盘三绳、杆上刻痕与秤砣，木斗盛粮 |
| 宫灯照影 | 红褐木架、八角顶罩、暖绢折面、梅枝纹与丝穗 |
| 纸鸢乘风 | 靛蓝与朱赭燕形纸鸢、竹骨、连续风线与绕线轴 |

这些是原创代码绘画意象，不是特定文物、工艺流程、度量制度、朝代服制或城门形制复原。印版与纸张上的纹字是无语义的装饰笔画，不是可引用的古籍原文；珠算与算筹的并置用于主题说明，不证明同一历史场景。杆秤未进行实际质量、力矩或刻度标定；用于技术讲解前需另核实。孔雀、松鼠为写意动物练习，不作为物种鉴定图。

每幅输出 1600×1000 透明 SVG/PNG；SVG 保留器物构件、植物、动物与陪景语义分组，稳定前缀 ID 与自包含滤镜。统一画册只扩展数据，继续使用 640px 透明 WebP 缩略图、滚动懒加载和按需大图；本辑进入“本次新作”，前辑保留原分类。

```bash
node scripts/generate-civilization-ink-studies.mjs
pnpm exec electron resources/skills/chinese-ink-elements/scripts/render-assets.cjs --input resources/visuals/traditional-culture/civilization-studies --overwrite
```
