# 楚汉风骨 · 秦末与西汉五人像

本辑为五幅原创代码彩墨人物素材，用于古代历史视频点景。项羽属于秦末楚汉之际，其余分别按楚汉、汉初或西汉边将取景。1600×1000 透明 SVG/PNG，牛皮纸 `#dfc69c` 只在预览层；可按组编辑衣冠、脸部、手、简册、弓矢、佩剑和人马关系。

## 角色与依据

| 作品 | 史载方向 | 本稿的表现与推演 |
| --- | --- | --- |
| 项羽 · 沉雄 | 《项羽本纪》长八尺余、力能扛鼎、被甲持戟、骏马名骓 | 宽颌、厚眉、较短的壮年脸与方收短髯，青铁甲搭朱赭披风，持缰佩剑；骏马在身侧，不画骑乘鞍镫。本稿没有画持戟动作。骓的灰褐毛色与脸部五官属于艺术选择，未将重瞳传闻画成双瞳。 |
| 刘邦 · 定汉 | 《高祖本纪》隆准、美须髯、竹皮冠与刘氏冠 | 成熟长面、较高鼻梁、垂长须与收拢手势；烟紫外氅衬赭褐内袍。长冠为简化解释，不能据此认定具体冠制、材质或袍色。 |
| 张良 · 从容 | 《留侯世家》太史公见图后评“状貌如妇人好女” | 清秀椭圆面、细眉垂目、较小口鼻、无须，窄肩持简；深靛青外衣与米白内袍、袖口明确分层。五官、发式、服色和佩剑属于推演，没有画成白须羽扇的后世谋士定式。 |
| 李广 · 守边 | 《李将军列传》长身、猿臂、善射、讷口少言 | 长颧面、窄眼、额纹、灰短髯与较长持弓臂，弓把与手掌相接，箭箙用三角背带固定；深褐披风、土黄袍袖和铁灰甲衣分层。为持弓静立，并非拉弓或射箭。弓制、甲色与具体军阶服饰未作精确复原。 |
| 韩信 · 审势 | 《淮阴侯列传》的军旅经历与统帅身份 | 转向凝视的青年瘦长面、清晰颌线、无须口鼻，绛红披风衬青灰甲和米白袖，持简审势、佩直剑；没有可靠面貌记载，年龄呈现与五官均为创作选择。 |

五人面部采用不同颌宽、鼻形、眼裂、眉量、须髯和视线；衣冠参考徐州博物馆西汉陶俑，秦陵藏品只作前置时代比较。交领有明确前后叠压，外层斜缘延至穿着者右侧；剑格缩为紧凑形体。马的尖耳、头颈、鬃与衔缰相接，未添加后世双侧马镫。甲片编缀、箭羽、简册编绳均保留可读结构。

## 五人重绘

按同脸、脸部豁口和衣披同色显胖的反馈，五人全部重新起稿。脸部轮廓用连续曲线，实体肤色不施加破边或侵蚀滤镜，转面淡染裁在面部内部；眼白内裁瞳孔，分别处理眼睑、鼻翼、唇线与须髯。重新安排肩、肘、腰和披风覆盖关系，降低原稿过宽的横向袍袖，外衣与内袍用明度、冷暖和色相分层。以上设色属于艺术选择，不宣称古代人物的固定服色。佩剑端部缩回画布内，甲片按实际画面尺度排布，肩甲不再挤成密集小网格。

重绘前的五组 SVG/PNG 备份在 `.scratch/han-figures-before-redraw/`；旧起稿脚本保留作过程记录，当前作品使用下列重绘生成器。

## 研究边界

史书形貌、出土形制、后世叙事分开记录。没有足以确认五人真实五官的同期肖像，不能把本稿称为真实容貌或服制复原。央视纪录片只核对官方简介与题材范围，没有声称完整观看或据镜头考据。具体来源、原文和文物照片见 [史料与形制核查](historical-references.md)。绘画路径全部原创，没有复制馆藏照片或第三方绘画。

## 重建与检查

在项目根目录依次运行：

```bash
node scripts/generate-han-figure-redraw.mjs
pnpm exec electron resources/skills/chinese-ink-elements/scripts/render-assets.cjs --input resources/visuals/traditional-culture/han-figures --overwrite
python3 scripts/preview-han-figure-studies.py
pnpm design:culture:gallery
```

本辑生成器只写入 `han-figures/ink-wash/`。总览为 `han-figures-preview.jpg`，五官对照为 `face-studies.jpg`，器物局部为 `portrait-details.jpg`，三底色检查为 `background-proof.jpg`。原 SVG/PNG 保持透明，纸底预览有独立文件。画册使用 WebP 缩略图与按需大图，保留全部旧作。
