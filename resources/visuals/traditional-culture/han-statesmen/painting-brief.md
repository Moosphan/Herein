# 汉家群像 · 文武与著史

日期：2026-10-29。当前五幅为用户反馈跨批次人物过于相似后的全员重画，覆盖本辑萧何、陈平、周勃、卫青和司马迁。每幅 1600×1000 透明 SVG/PNG，牛皮纸和题字仅存在于预览。先前版本保留在 `.scratch/han-statesmen-before-individual-redraw/`；项羽、刘邦、张良、李广、韩信及其他作品原样保留。

共同朝代的右衽、束带和简牍形制有共性，个体的面骨、发式轮廓、衣物组合、体态与完整配色分别设计。没有为追求不同而添加现代发型、明清甲胄或未经核查的专属兵器。五人的可信同期写生肖像均未取得；表中设计不能称为本人容貌复原。详见 [史料核查](historical-references.md)。

## 重画方法与检查

前版虽分别写了头像函数，仍使用近似的头身比例、眼鼻位置、甲衣与双肩披风组合；与韩信、李广等旧作并排后容易读成同一人物换配色。这次五人的脸、身体、冠发与整件服装路径均重新起稿，代码只复用笔刷和 SVG 路径等底层绘图函数，不再导入旧版的眼、脸、甲衣、领口、束带和佩剑造型函数。

实际检查本辑全图、五官、六处手部/甲衣/案面细节，以及暖纸、白、深色底；并将项羽、刘邦、张良、李广、韩信原作与本辑同列检查五官和完整轮廓。跨批次对照放在 `.scratch/statesmen-cross-batch.jpg`，不加入作品分类。修整陈平颈部与下颏衔接，收敛卫青和司马迁脸缘的鼻部突起；脸内淡染裁在实体脸内，眼白内裁瞳孔，不使用轮廓噪声位移。

五人衣袍、持物与手势分别起稿。简册由手或承盘支撑；周勃佩剑与手掌、剑柄及腰侧有连接；司马迁笔杆、握点、笔锋和简牍位于同一书写投影，家具保持低案意象。所有未证明的甲片排列、服色和个人用具标为艺术设计。

## 重建

依次运行，生成器成功后再导出，避免混合版本：

```bash
node scripts/generate-han-statesmen.mjs
pnpm exec electron resources/skills/chinese-ink-elements/scripts/render-assets.cjs --input resources/visuals/traditional-culture/han-statesmen --overwrite
python3 scripts/preview-han-statesmen.py
pnpm design:culture:gallery
```

总览 `han-statesmen-preview.jpg`，五官 `face-studies.jpg`，六处动作细节 `portrait-details.jpg`，三底色 `background-proof.jpg`。画册以透明 WebP 缩略图和按需大图展示；原 SVG/PNG 用于编辑与下载。
