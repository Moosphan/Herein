# 四时与人间 · 彩墨十二景

延续现有彩墨与暖纸定调，新增花木、生灵、器物和乡野空间。牡丹用胭脂，石榴用赭红，青瓷用青釉，礼器与竹笙分别保留铜金和竹黄。透明素材不写入展示纸底，不替换前辑作品。

| 作品 | 构图与画法重点 |
| --- | --- |
| 牡丹绣石 | 大小花错落、重瓣叠染、疏叶与透孔园石 |
| 榴实盈枝 | 斜枝长叶、赭红圆果、裂口分室与籽粒 |
| 蕉雨听石 | 阔叶侧锋、叶脉与破缘、叶鞘和根石 |
| 桂影月兔 | 淡月、金桂、灰白兔毛、耳根与坐姿 |
| 苍鹰守岩 | 敛翼警觉、钩喙眉眼、羽层与爪石接触 |
| 青瓷含莲 | 莲瓣器口、凹口内壁、釉色与刻花底足 |
| 铜爵礼影 | 流、尾、双柱、环把、三足与铜色转面 |
| 笙竹和鸣 | 参差竹管、管口、木斗与吹管连接 |
| 投壶矢趣 | 修颈壶身、双耳、插矢与侧置箭矢 |
| 桔槔汲古 | 木架、支点、杠杆、配重、绳桶与石井 |
| 汀渡横舟 | 低矮临水栈台、短木桩、登船踏板、系泊绳、舟桨与水岸 |
| 驿路秋舍 | 驿站牌匾与悬挂招牌、拴马栏、系驾驿马、带篷木轮驿车、瓦檐与秋树 |

这些是原创题材意象，不对应某件出土文物、真实驿站或精确器械复原。桂兔属于文学节令意象；铜爵、笙、投壶与桔槔不用于证明具体朝代形制、调音机制或工程能力。用于史实解说时另核实对象和年代。

驿舍与渡口按用户反馈修订：驿舍用明确文字标识、马匹、车轮、车辕与拴马设施说明功能；渡口改为与水面接近的单层栈台，缩短露出水面的桩段，船舷与栈台间补踏板。牌子上的“驿站”是题材识别文字，不是某个历史驿站的真实匾额；马具和驿车保留原创意象边界。

输出为 1600×1000 透明 SVG/PNG；语义分组保留植物、动物、器物构件与陪景。画册使用 640px 透明 WebP 缩略图，按需加载最大 1600px 预览。
